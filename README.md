# monkey_pet

**Bit**, a pixel pet that grows from your Monkeytype grind. Single-file, no build step.

- Sync a public Monkeytype username for totals (tests, time, best WPM)
- Optional ApeKey (stored in your browser only) unlocks the 20-week heatmap and daily quest
- 5 evolution stages, streak-driven moods, speed badges, pettable pet
- Demo mode works offline

Open `index.html` or host it with GitHub Pages.
