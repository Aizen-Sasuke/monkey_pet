# Bit, the typing pet

A pixel pet that grows when you type. Static site, no build step.

## Run it
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy on GitHub Pages
Settings, Pages, Source: `main` branch, `/ (root)`.

## Edit it
- `app.js`: sprites, stages, XP thresholds and typing passages are at the top.
- `style.css`: theme colours are the variables at the top.
- Progress is saved in the browser's localStorage. Monkeytype sync uses the public profile API.
